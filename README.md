# CSCI 645 HW2: Imitation Learning for Robot Manipulation

**Task:** MuJoCo Playground `PandaPickCube` (Franka Panda, JAX/MJX backend, state observations).
**Teacher:** scripted pick-and-place expert (IK + gravity-compensated joint targets).
**Student:** Diffusion Policy (state-based, 1-D temporal conditional U-Net, DDPM).
**Ablation (Option A):** dataset quantity, 25 vs 50 vs 100 demonstrations (nested subsets), 3 training seeds each.

The report is `report.pdf`. This README explains how to reproduce every number and figure in it.

## Results at a glance

See `results/summary_table.md` (generated by `code/analyze.py`) and the figures in `results/`.

## How to reproduce

All steps run on **one** GPU platform per sweep (Colab or CARC). Every script takes
`--set key=value` overrides on top of its YAML config.

### Option 1: Google Colab (T4)
Open `notebooks/run_pipeline.ipynb`, set `REPO_URL` in the first cell, and run the cells in order.
The notebook clones the repo, installs `requirements.txt`, and runs the pipeline below,
pushing results back to GitHub after every finished run.

### Option 2: USC CARC Discovery
```bash
bash slurm/setup_carc.sh                     # on a login node, once (uv venv + kernel + assets)
# Either open notebooks/run_pipeline.ipynb in OnDemand JupyterLab with the "Python (hw2)" kernel,
# or run unattended:
sbatch slurm/run_pipeline.sbatch
```

### The pipeline (what both options execute)
```bash
python tests/test_cpu.py                                  # unit tests
python code/smoke_test.py                                 # env dims, expert success, render, speed
python code/collect_demos.py                              # 100 successful demos (seeds 0, 1, ...)
python code/inspect_demos.py                              # stats, figures, expert videos
python code/evaluate.py --teacher --out-dir results/teacher_eval --video-dir videos/teacher_eval
python code/run_sweep.py                                  # 3 sizes x 3 seeds: train + evaluate
python code/analyze.py                                    # table + figures
```

## Design details

**Environment.** `registry.load("PandaPickCube", config_overrides={"impl": "jax"})`, unmodified:
control step 0.02 s (4 physics substeps of 0.005 s), 150 steps per episode (3 s). Reset
randomizes the box xy position (±0.2 m) and the target position (xy ±0.2 m, height 0.2-0.4 m above
the box's rest height). Each episode is reset from `jax.random.PRNGKey(seed)`.

**Observation (66-D, from the env).** qpos (16: 7 arm joints, 2 fingers, box free joint),
qvel (15), gripper position (3), gripper rotation (6), box rotation (6), box minus gripper (3),
target minus box (3), target-box rotation difference (6), ctrl minus qpos (8).

**Action (8-D in [-1, 1]).** Change of the actuator position targets: ctrl <- clip(ctrl + 0.04 * a).
That is 7 arm joint targets (rad) plus 1 finger-opening target (m).

**Success.** PandaPickCube defines no success flag, so we define one before running any
experiment: the box centre is within **5 cm** of the target at the **final** step, and the box never
went out of bounds. `results/fig_success_vs_threshold.png` reports 2, 3, 5 and 10 cm as well.

**Teacher.** A phase machine (approach, descend, grasp, lift, transport). A Cartesian reference
moves toward each waypoint under a speed limit. Damped least-squares IK (position + downward
orientation, null-space pull to the home pose) produces joint targets, plus gravity feedforward
`g(q)/kp`, because the model's position servos sag under gravity. If the box slips, the teacher
regrasps. All attempts are stored with labels, and training uses the successful ones (the
filtering is reported).

**Student.** Diffusion Policy, adapted from Chi et al.'s official state-based notebook:
- **Network:** ConditionalUnet1D with down dims 128/256/512 and FiLM conditioning on the 2 most recent observations.
- **Horizons:** predicts 16 actions and executes 8 before replanning (receding horizon).
- **Diffusion:** 100-step DDPM, squaredcos_cap_v2 schedule, trained to predict the added noise.
- **Optimization:** AdamW with lr 1e-4 and weight decay 1e-6, 500 warmup steps then cosine decay, EMA of the weights (power 0.75), batch 256.
- **Training length:** 20k gradient steps for **every** dataset size.
- **Normalization:** each observation and action dimension is min-max normalized to [-1, 1], with statistics computed on the training subset.

**Seeds.**
- Demonstrations: env seeds 0, 1, 2, ... The n-demo subset is the first n successes in seed order, so the sets are nested.
- Evaluation: env seeds 100000-100099 (100 held-out initial conditions), the same for every condition and for the teacher.
- Training seeds: 0, 1, 2.

**Provenance.** Every JSON in `results/` contains `system_info` (Python, GPU, package versions,
git commit), and every run directory contains its fully resolved `config.yaml`.
